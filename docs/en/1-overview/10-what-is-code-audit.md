# What is code-audit

code-audit checks the changes on a branch against that project's rules and gives a verdict with a report.

## What exists today

The repository contains a command line skeleton that prints help and version information, a YAML frontmatter reader, a build script, and a documentation checker. The `init`, `check`, and `review` commands report that they are not available. The project can be built and run from its development checkout.
