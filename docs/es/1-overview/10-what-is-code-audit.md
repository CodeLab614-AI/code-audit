# Qué es code-audit

code-audit revisa los cambios de una rama contra las reglas de ese proyecto y entrega un dictamen con un informe.

## Qué existe hoy

El repositorio contiene un esqueleto de línea de comandos que muestra la ayuda y la versión, un lector de metadatos YAML al inicio de documentos, un script de compilación y un comprobador de documentación. Los comandos `init`, `check` y `review` responden que no están disponibles. El proyecto se puede compilar y ejecutar desde su copia local.
